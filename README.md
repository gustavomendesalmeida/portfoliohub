# PortfolioHUB

Plataforma centralizada para exibir e gerenciar meus projetos e portfólios digitais.

## Tecnologias
- HTML, CSS e JavaScript
- Git e GitHub (controle de versão e colaboração)
- Google Gemini (apoio na implantação)

## Como usar
1. Clone o repositório: `git clone https://github.com/gustavomendesalmeida/portfoliohub.git`
2. Abra o arquivo `index.html` no navegador.
3. Para adicionar um projeto, edite a lista `projetos` dentro do `index.html`.

## Colaboração
- Fluxo: branch → commit → pull request → revisão → merge na `main`.
- Commits no padrão `feat:`, `fix:`, `docs:`.
- A branch `main` é protegida e exige pull request.

## Segurança
- 2FA ativado na conta.
- Secret scanning e Dependabot ativados.
- Arquivos sensíveis ignorados pelo `.gitignore`.
